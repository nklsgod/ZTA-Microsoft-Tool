ZT Workshop Task Manager

Load a zt-framework-config-*.json export from zerotrust.microsoft.com, filter by status/priority/team/tags, edit them, then export a file that re-imports cleanly into the official tool. Everything runs locally in this browser tab — nothing is uploaded anywhere.

Team priority, team, feature number, link, and tags are parsed from each task's existing notes text using the format Status | Prio 1-3 | Team | FeatureNr | Link #tag (e.g. Status | Prio 3 | SAM2 | xyz123 | https://test.com #1337) — the convention already in use, not something invented by this tool. "Team priority" (1-3) is separate from the official Priority field below.

Custom fields are parsed from & written back into each task's existing notes field — a plain string the official importer already accepts — so everything travels with the file and stays visible even if someone opens it directly in the official app. The "Notes (freeform fallback)" column only applies when Team priority/Team/Feature/Link are all empty for that row; as soon as any of those are filled in, the note is written in the Status | Prio N | Team | FeatureNr | Link #tag format instead. This tool only edits task overrides that are already present in the loaded file; to start tracking a brand-new task, set its status once in the official app, re-export, then continue here.
